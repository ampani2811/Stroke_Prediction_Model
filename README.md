# Stroke_Prediction_Model
This project applies data science and artificial intelligence techniques to analyze health data and predict the likelihood of stroke, with the goal of contributing to early intervention and reducing stroke-related deaths.
# Objective:
To build a machine learning model that predicts the likelihood of stroke based on patient health data.
# tools used 
- Python
- Pandas
- Scikit-learn
- Excel / Dataset
# How it works
The dataset is cleaned and processed, then used to train a machine learning model that predicts stroke risk.
